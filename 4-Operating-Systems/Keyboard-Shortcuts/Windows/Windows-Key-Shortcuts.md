The Windows key is the windows logo or "Win" key found on many keyboards. This key is also commonly known as the Super, or Meta key. <br>

| Shortcut                       | Action                                                        |
| ------------------------------ | ------------------------------------------------------------- |
| Windows key + E                | Open File Explorer                                            |
| Windows key + I                | Open Settings                                                 |
| Windows key + R                | Open Run dialog                                               |
| Windows key + S                | Open Search                                                   |
| Windows key + D                | Show or hide desktop                                          |
| Windows key + M                | Minimize all windows                                          |
| Windows key + Shift + M        | Restore minimized windows                                     |
| Windows key + Tab              | Open Task View                                                |
| Windows key + A                | Open Action Center (Windows 10) / Quick Settings (Windows 11) |
| Windows key + X                | Open Quick Link menu                                          |
| Windows key + V                | Open Clipboard history                                        |
| Windows key + .                | Open Emoji panel                                              |
| Windows key + P                | Choose display projection mode                                |
| Windows key + K                | Open Connect panel                                            |
| Windows key + U                | Open Accessibility settings                                   |
| Windows key + L                | Lock computer                                                 |
| Windows key + Ctrl + D         | Create a new virtual desktop                                  |
| Windows key + Ctrl + ←         | Switch to virtual desktop on the left                         |
| Windows key + Ctrl + →         | Switch to virtual desktop on the right                        |
| Windows key + Ctrl + F4        | Close current virtual desktop                                 |
| Windows key + Shift + ←        | Move window to the monitor on the left                        |
| Windows key + Shift + →        | Move window to the monitor on the right                       |
| Windows key + ←                | Snap window to the left                                       |
| Windows key + →                | Snap window to the right                                      |
| Windows key + ↑                | Maximize window                                               |
| Windows key + ↓                | Restore or minimize window                                    |
| Windows key + Home             | Minimize all windows except the active one                    |
| Windows key + Shift + S        | Capture a selected area of the screen                         |
| Windows key + PrtScn           | Save a screenshot to Pictures\Screenshots                     |
| Windows key + G                | Open Xbox Game Bar                                            |
| Windows key + Alt + R          | Start or stop screen recording                                |
| Windows key + T                | Cycle through taskbar apps                                    |
| Windows key + B                | Focus the notification area (system tray)                     |
| Windows key + 1–9              | Open or switch to the corresponding taskbar app               |
| Windows key + F                | Open Feedback Hub                                             |
| Windows key + H                | Start voice typing                                            |
| Windows key + +                | Open Magnifier and zoom in                                    |
| Windows key + -                | Zoom out with Magnifier                                       |
| Windows key + Esc              | Close Magnifier                                               |
| Windows key + Space            | Switch keyboard language or layout                            |
| Windows key + Shift + Space    | Switch to the previous keyboard layout                        |
| Windows key + Ctrl + Shift + B | Reset the graphics driver                                     |
| Windows key + Pause            | Open System information                                       |
