## General accessibility

| Shortcut        | Action                      |
| --------------- | --------------------------- |
| Windows key + U | Open Accessibility settings |

## Narrator (screen reader/text to speech)

| Shortcut                   | Action                      |
| -------------------------- | --------------------------- |
| Windows key + Ctrl + Enter | Turn Narrator on or off     |
| Windows key + Ctrl + N     | Open Narrator settings      |
| Windows key + Enter        | Start Narrator (Windows 10) |

## Speech recognition (speech to text)

| Shortcut               | Action                                       |
| ---------------------- | -------------------------------------------- |
| Windows key + Ctrl + S | Open Windows Speech Recognition (Windows 10) |

## Magnifier (zoom and visibility)

| Shortcut                 | Action                               |
| ------------------------ | ------------------------------------ |
| Windows key + +          | Open Magnifier and zoom in           |
| Windows key + -          | Zoom out with Magnifier              |
| Windows key + Esc        | Close Magnifier                      |
| Ctrl + Alt + Mouse wheel | Zoom in or out with Magnifier        |
| Ctrl + Alt + I           | Invert colors in Magnifier           |
| Ctrl + Alt + F           | Switch to full-screen Magnifier view |
| Ctrl + Alt + L           | Switch to lens Magnifier view        |
| Ctrl + Alt + D           | Switch to docked Magnifier view      |
| Ctrl + Alt + Arrow keys  | Pan in the Magnifier view            |

## Color and contrast

| Shortcut                   | Action                       |
| -------------------------- | ---------------------------- |
| Windows key + Ctrl + C     | Turn color filters on or off |
| Alt + Shift + Print Screen | Turn High Contrast on or off |

## Keyboard accessibility

| Shortcut                         | Action                     |
| -------------------------------- | -------------------------- |
| Windows key + Ctrl + O           | Open On-Screen Keyboard    |
| Left Alt + Left Shift + Num Lock | Turn Mouse Keys on or off  |
| Press Shift five times           | Turn Sticky Keys on or off |
| Hold Right Shift for 8 seconds   | Turn Filter Keys on or off |
| Hold Num Lock for 5 seconds      | Turn Toggle Keys on or off |
