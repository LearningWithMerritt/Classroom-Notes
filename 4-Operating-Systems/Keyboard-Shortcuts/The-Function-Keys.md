Function keys (F1–F12) are special keys found along the top row of most computer keyboards. They perform shortcuts and commands in applications, web browsers, document editors, and system utilities.

IMPORTANT! : These functions are not universal: the same key may perform different actions depending on the active application.

Function keys can be programmable or application-dependent, so their behavior isn't guaranteed to be the same across programs or keyboards.
- F1, F2, F5, F10, and F11 have common conventions in many applications, but these are not universal.
- F3, F4, F6, F7, F8, F9, and F12 have particularly varied uses across applications.
- Programmable keyboards and software can assign custom actions to any function key.
- Laptop keyboards may assign hardware controls, such as volume and brightness, to the same keys.

## Function keys (F1–F12)

| Key | Common function                                             |
| --- | ----------------------------------------------------------- |
| F1  | Opens Help in many applications.                            |
| F2  | Renames a selected file or item in some applications.       |
| F3  | Opens the find menu in many applications.                   |
| F4  | Different for different applications.                       |
| F5  | Refreshes or reloads the current view in many applications. |
| F6  | Different for different applications.                       |
| F7  | Different for different applications.                       |
| F8  | Different for different applications.                       |
| F9  | Different for different applications.                       |
| F10 | Activates the menu bar in many desktop applications.        |
| F11 | Toggles full-screen mode in many applications.              |
| F12 | Different for different applications.                       |

## Common function-key combinations

| Shortcut    | Common function                                                                       |
| ----------- | ------------------------------------------------------------------------------------- |
| Alt + F4    | Closes the active window or application in many desktop environments.                 |
| Ctrl + F4   | Closes the active document or internal window in some applications.                   |
| Shift + F10 | Opens the context menu for a selected item.                                           |
| Ctrl + F5   | Forces a refresh in some web browsers and applications.                               |
| Alt + F10   | Maximizes, restores, or activates a window or interface element in some applications. |
| Shift + F3  | Changes text capitalization in some word processors.                                  |
| Ctrl + F    | Finds text or items in many applications.                                             |
| Alt + Enter | Opens properties or displays details for a selected item in some applications.        |
